## How to Take Screenshots on Windows

1. **Snipping Tool:** `Win + Shift + S` → Select area → Paste into Paint → Save here
2. **Full Screen:** `PrtScn` key → Paste into Paint → Save here
3. **Active Window:** `Alt + PrtScn` → Paste into Paint → Save here
